# 🌍 IP to Location Tracker (Termux/Linux/Windows)

পাইথন দিয়ে তৈরি একটি প্রিমিয়াম এবং দ্রুতগতির IP লোকেশন ট্র্যাকার টুল। এই টুলটির মাধ্যমে যেকোনো পাবলিক আইপি অ্যাড্রেসের বিস্তারিত তথ্য (যেমন: দেশ, শহর, অঞ্চল, জিপ কোড, আইএসপি, এবং লোকেশন) জানা যাবে।

## ⚡ ফিচারসমূহ (Features)
- 🚀 দ্রুত এবং নির্ভুল আইপি লোকেশন ট্র্যাকিং
- 🎨 সুন্দর এবং প্রিমিয়াম সিএলআই (CLI) ইন্টারফেস
- 📍 বিস্তারিত তথ্য প্রদর্শন (দেশ, শহর, অঞ্চল, আইএসপি, অক্ষাংশ ও দ্রাঘিমাংশ)
- 🛑 কিবোর্ড ইন্টারাপ্ট (Ctrl+C) হ্যান্ডেল করা 

## 📥 ইনস্টলেশন এবং ব্যবহার (Installation & Usage)

### টার্মাক্সের জন্য (For Termux - Android)
```bash
pkg update && pkg upgrade -y
pkg install python -y
pip install requests
git clone https://github.com/mustaieen/ip-to-location.git
cd ip-to-location
python main.py

উইন্ডোজ / লিনাক্সের জন্য (For Windows / Linux)

git clone https://github.com/mustaieen/ip-to-location.git
cd ip-to-location
pip install -r requirements.txt
python main.py
